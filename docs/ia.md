# Declaração de Uso de Inteligência Artificial

Conforme as diretrizes do curso, o uso de assistentes de IA foi empregado para apoio na estruturação dos arquivos de configuração, sugestão de padrões arquiteturais (ADR), modelagem do documento OpenAPI e formatação do relatório de desempenho.

## Prompts Principais Utilizados:
1. *"Como estruturar o ADR 001 justificando o uso de Node.js, PostgreSQL e Docker para o Projeto B?"*
2. *"Como estruturar o arquivo openapi.yaml para a rota de usuários?"*
3. *"Como definir um SLO simples e um script k6 para medir o p95 de latência?"*

Todas as decisões finais de código, validação de funcionamento e testes foram revisadas e validadas.
